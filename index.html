The project

About HarvestBound

Description

HarvestBound is a simple 2D farming game made in Godot. The player manages a small farm by planting, watering, and harvesting crops. The game has four seasons, and each season gives the player different tasks to complete.

General objectives

Create a simple and fun 2D farming game where players can experience basic farming and manage their farm through different seasons.

Specific objectives

  • Plant, water, and harvest crops.
  • Include Spring, Summer, Autumn, and Winter.
  • Earn money by selling crops.
  • Complete tasks for each season.
  • Add basic player movement and interaction.
  • Create the game using Godot.

Goal

Survive all four seasons by taking care of the farm, completing tasks, and earning enough money to keep the farm running.

Benefits

  • Players: A simple and enjoyable farming game.
  • Students: Practice programming and game development.
  • Learning: Explore basic farming and resource management.
  • Teamwork: Give each member a chance to contribute.

Conclusion

HarvestBound focuses on planting, harvesting, earning money, and surviving the four seasons. It also helps improve skills in Godot, programming, and teamwork.
